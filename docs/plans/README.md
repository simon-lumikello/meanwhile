# Plans

Work that spans several sessions keeps a plan here, one Markdown file per piece of work, so a fresh
session can pick it up without the previous conversation. A plan holds:

- **Goal and approach:** what the work changes and why, and the decisions already settled.
- **Tasks** with stable IDs (`A1`, `A2`, …), checkboxes, dependencies, and acceptance criteria.
- **Evidence:** what verified each finished task, local or remote.
- **Resume record:** dated entries saying where the work stands, what comes next, and any blockers.

A plan describes work in progress, not the repository. Once the work has shipped, delete the plan:
the code, the READMEs, and the `AGENTS.md` files describe the result.
